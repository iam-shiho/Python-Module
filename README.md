# Python Piscine

This project has been created as part of the 42 curriculum by swaragay.

## Description

本プロジェクトは、42カリキュラムにおける Python Piscine（`python00` 〜 `python10`）の課題群です。各モジュールを通して、Pythonの基礎文法からオブジェクト指向、標準ライブラリの活用、例外処理、ファイル操作、テストなどを段階的に習得することを目的としています。

各モジュールでは、使用した組み込み関数・標準ライブラリのメソッド・自作関数について、その役割と使い方を整理しています。

| ex0 | `def 変数名(引数)` | def(define): 関数を定義するときのキーワード。<br>関数に返り値を設定していない場合は'None'がデフォルトで返される。<br>引数に＝をつけることでデフォルト値（対応する引数がなかった場合に入る値）を設定できる。<br>引数の数があっていない場合は'TypeError'が発生する。|

| ex1 | `: (型の名前)` | アノテーション。pythonは'動的型付け'で、明示的に型を宣言しなくていい。<br>そのため、代入された値を元に型が決まる。（型を宣言しないとmypy --strictに引っかかる）|

| ex2 | `int(引数)` | int関数。文字列やfloat型、bool値(1,0)をintに変換させる。<br>float型は小数点以下は切り捨てられる。12.34 -> 12 <br>数字ではない文字や文字列のfloat（'1.42'）は'ValueError'になる。|
| ex2 | `range((開始値), 終了値, ステップ)` | range関数。連続した数字の並びを作成する。開始値を指定しない場合は０から始まる。終了値は整数（０以下の数は含まない）で、生成される数列の終点を表します。ステップは増分値を指定できる。ex:range(3) -> 0, 1, 2  range(1,4) -> 1, 2, 3　range(2, 11, 2) -> 2, 4, 6, 8, 10|

## Instructions

### 実行方法

```bash
python3 [ファイル名].py
```

### Lintチェック(flake8)

本プロジェクトでは flake8 によるコードスタイルチェックを行っています。

```bash
flake8 .
```

### 型チェック(mypy)

```bash
#[ファイル名].py でも可能。　.はすべてのファイルを表している
mypy

#関数の返り値やアノテーションがあるかより詳細に見てくれる
mypy . --strict
```
