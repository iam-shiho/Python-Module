# Python Piscine

This project has been created as part of the 42 curriculum by swaragay.

## Description

本プロジェクトは、42カリキュラムにおける Python Piscine（`python00` 〜 `python10`）の課題群です。各モジュールを通して、Pythonの基礎文法からオブジェクト指向、標準ライブラリの活用、例外処理、ファイル操作、テストなどを段階的に習得することを目的としています。

各モジュールでは、使用した組み込み関数・標準ライブラリのメソッド・自作関数について、その役割と使い方を整理しています。

* <sub>※3 rose = plant() 変数に代入すること</sub>

**if __name__ == '__main__'とは**:
まずPythonインタープリターは、モジュール<sup>※1</sup>を読み込むと__name__という変数を設定する。メインプログラム<sup>※2</sup>だった際は__name__が__main__に設定される。しかしインポート<sup>※3</sup>されている側のモジュールはファイル名に設定される。

メインプログラムだった際にそのif文の中身が実行される（≒ main関数）また、インポートされた時(else)に実行内容を制限したりできる。
<sub>※1 拡張子 .py が付くファイル(pythonファイル)</sub>
<sub>※2 python3 (ファイル名)<- これがメインプログラム　</sub>
<sub>※3 import (ファイル名)<- ヘッダーみたいな感じ。他のモジュールでつくった関数などを呼び出す際に使う。</sub>

## Instructions

### 実行方法

```bash
python3 [ファイル名].py
```

### Lintチェック(flake8)

本プロジェクトでは flake8 によるコードスタイルチェックを行っています。

```bash
flake8 .
```

### 型チェック(mypy)

```bash
#[ファイル名].py でも可能。　.はすべてのファイルを表している
mypy

#関数の返り値やアノテーションがあるかより詳細に見てくれる
mypy . --strict
```
